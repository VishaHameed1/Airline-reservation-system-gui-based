# ✈️ Airline Reservation System (C++ GUI)

A robust desktop application built using **C++** and **Object-Oriented Programming (OOP)** principles. This system manages flight bookings, passenger records, and ticketing through an intuitive Graphical User Interface (GUI).

## 🛠️ Technical Implementation (OOP)
This project demonstrates core OOP concepts:
- **Encapsulation:** Secure handling of passenger data and flight details within classes.
- **Inheritance:** Specialized classes for different types of flights (Domestic/International).
- **Polymorphism:** Method overriding for dynamic ticket pricing and seat allocation.
- **File Handling:** Persistent storage using `.dat` or `.txt` files to save booking history.



## ✨ Key Features
- **Interactive GUI:** User-friendly forms for booking and flight searching.
- **Flight Management:** Admin capabilities to add, remove, or modify flight schedules.
- **Ticket Generation:** Automated generation of digital boarding passes.
- **Real-time Validation:** Checks for seat availability and valid user inputs.

## 💻 Tech Stack
- **Language:** C++
- **IDE:** (e.g., VS Code / Dev C++ / Code::Blocks)
- **Database:** Flat File System (File Handling)
